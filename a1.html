A1: Blink — Three LEDs

HCDE • Arduino Uno • Red LEDs • Resistors sized for 5V logic

Firmware (Arduino Code)

This code runs on the Arduino Uno and controls three red LEDs connected in parallel (each with its own resistor) to pin 13. All LEDs blink together at a 1-second interval. 

// ---------------------------------------------------------
    
    void setup() {
      // Initialize digital pin 13 as an output
      pinMode(13, OUTPUT);
    }
    
    void loop() {
      // Turn all LEDs ON
      digitalWrite(13, HIGH);
      delay(1000); // Wait for 1 second
    
      // Turn all LEDs OFF
      digitalWrite(13, LOW);
      delay(1000); // Wait for 1 second
    }

2) How many LEDs could blink independently? How much current?

You can blink about 10-12 LEDs at once. If every LED is on at once at 20mA each, that would amount to about 200 mA total for the system.

4) How fast until you can’t tell they’re blinking?

The limit is around 60hz. If it is any higher it will be hard to tell that the LEDs are blinking.
