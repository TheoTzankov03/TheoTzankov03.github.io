A3: Light-Responsive LED Brightness — LDR + Potentiometer

Arduino Uno • LDR → A0 • Potentiometer → A1 • RGB on 9/10/11

This project uses a photoresistor (LDR) and a 10 kΩ potentiometer as a voltage divider to measure ambient light on A0 and adjust the brightness of an LED (or small LED array) with PWM on D11. A threshold prevents the LED from lighting in low-light conditions.

The firmware uses analogRead(), map(), analogWrite(), and an if statement. It prints custom messages to the Serial Monitor describing sensor readings and output state.

Arduino Code (Line-by-Line Comments)

   // Input
        const int sensorPin = A0;  // LDR divider:
        const int potPin    = A1;  // Pot divider: 
        
        // RGB LED pins 
        const int G = 9;
        const int B = 10;
        const int R = 11;
        
        void setup() {
          Serial.begin(9600);
          pinMode(R, OUTPUT);
          pinMode(G, OUTPUT);
          pinMode(B, OUTPUT);
        }
        
        void loop() {
          // Read sensors
          int sensorValue = analogRead(sensorPin);   // 0 - 1023 from LDR
          int potRaw      = analogRead(potPin);      // 0 - 1023 from pot 
        
          // Pot maps to a movable threshold range (1 - 900)
          int threshold = map(potRaw, 0, 1023, 1, 900);
          int band2     = min(threshold + 200, 1023);  // upper split
        
          // Brightness follows LDR level
          int brightness = map(sensorValue, 0, 1023, 0, 255);
        
          // Select color by range
          if (sensorValue < threshold) {
            analogWrite(G, brightness); // set to green
            analogWrite(B, 0);
            analogWrite(R, 0);
            Serial.print("LDR="); Serial.print(sensorValue);
            Serial.print("  THR="); Serial.print(threshold);
            Serial.print("  -> GREEN  PWM="); Serial.println(brightness);
          } else if (sensorValue < band2) {
            analogWrite(G, 0);
            analogWrite(B, brightness); // set to blue
            analogWrite(R, 0);
            Serial.print("LDR="); Serial.print(sensorValue);
            Serial.print("  THR="); Serial.print(threshold);
            Serial.print("  -> BLUE   PWM="); Serial.println(brightness);
          } else {
            analogWrite(G, 0);
            analogWrite(B, 0);
            analogWrite(R, brightness); // set to red
            Serial.print("LDR="); Serial.print(sensorValue);
            Serial.print("  THR="); Serial.print(threshold);
            Serial.print("  -> RED    PWM="); Serial.println(brightness);
          }
          delay(50); // small delay for visuals
        }

Operation & Serial Output

The LDR on A0 produces a voltage that rises with light. The potentiometer on A1 is a separate divider and sets a movable threshold (mapped to ~1–900). The firmware compares A0 to this threshold: as light increases, the A0 reading increases and the LED response changes bands; turning the pot shifts the trigger point without rewiring. A0 is also mapped to PWM (0–255) so brightness scales with light level.

Additional Questions

1) Can the variable resistor be either R₁ or R₂?

Yes. The variable resistor can be either R₁ or R₂ in a voltage divider. If it’s on the top (R₁), the output voltage decreases as resistance increases. If it’s on the bottom (R₂), the output voltage increases as resistance increases. The math is the same, only the direction of the voltage change is reversed.

3) What if analogRead was 16-bit and analogWrite was 10-bit?

The map() function would need to match those new bit ranges. Instead of map(sensorValue, 0, 1023, 0, 255), you would write map(sensorValue, 0, 65535, 0, 1023). This would give finer control because both input and output have more resolution.
