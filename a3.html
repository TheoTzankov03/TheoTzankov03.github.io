A3: Light-Responsive LED Brightness — LDR + Potentiometer

Arduino Uno • LDR + 10 kΩ (pot) voltage divider → A0 • PWM LED on D11

Overview

This project uses a photoresistor (LDR) and a 250 kΩ potentiometer as a voltage divider to measure ambient light on A0 and adjust the brightness of an LED (or small LED array) with PWM on D11. A threshold prevents the LED from lighting in low-light conditions.

The firmware uses analogRead(), map(), analogWrite(), and an if statement. It prints custom messages to the Serial Monitor describing sensor readings and output state.

Physical Circuit

Arduino Code (Line-by-Line Comments)

   //const int sensorPin = A0;     // Photoresistor input 
        const int outputPin = 11;      // PWM output 
        int sensorValue = 0;          // Stores analog reading (0–1023)
        int outputValue = 0;          // Stores PWM value (0–255)
        
        void setup() {
          Serial.begin(9600);         // Start Serial Monitor
          pinMode(outputPin, OUTPUT);
        }
        
        void loop() {
          // Read analog sensor value
          sensorValue = analogRead(sensorPin);
        
          // Map the 0–1023 range, 0–255 for PWM output
          outputValue = map(sensorValue, 0, 1023, 0, 255);
        
          // turn off output in low light
          if (sensorValue < 200) {
            analogWrite(outputPin, 0);  // Too dark, turn off output
            Serial.print("Low light (");
            Serial.print(sensorValue);
            Serial.println(") → Output OFF");
          } 
          else {
            analogWrite(outputPin, outputValue);
            Serial.print("Light level: ");
            Serial.print(sensorValue);
            Serial.print(" → Output PWM: ");
            Serial.println(outputValue);
          }
          
        }

Additional Questions

1) Can the variable resistor be either R₁ or R₂?

Yes. The variable resistor can be either R₁ or R₂ in a voltage divider. If it’s on the top (R₁), the output voltage decreases as resistance increases. If it’s on the bottom (R₂), the output voltage increases as resistance increases. The math is the same, only the direction of the voltage change is reversed.

3) What if analogRead was 16-bit and analogWrite was 10-bit?

The map() function would need to match those new bit ranges. Instead of map(sensorValue, 0, 1023, 0, 255), you would write map(sensorValue, 0, 65535, 0, 1023). This would give finer control because both input and output have more resolution.
