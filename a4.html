A2: Hand Distance — Ultrasonic + RGB LED

HCDE • Arduino Uno • HC-SR04 • RGB LED • 220 Ω resistors • NewPing

Overview

This assignment measures how far a hand is from an HC-SR04 ultrasonic sensor and maps that distance to distinct colors on a common-cathode RGB LED. The sketch prints the measured distance to the Serial Monitor and displays proximity bands (e.g., red when close, blue when far).

Firmware (Arduino Code)

The firmware uses NewPing.h to simplify echo timing and distance conversion. Distances are shown in inches and divided into six evenly spaced color bands from 0–120 in. 

// ---------------------------------------------------------
// A2: Hand Distance — HC-SR04 + RGB LED (NewPing)
// Wiring:
//   HC-SR04: VCC->5V, GND->GND, TRIG->D9, ECHO->D8
//   RGB LED (common-cathode): R->D3, G->D5, B->D6 (each with 220Ω), cathode->GND

#include NewPing.h

    // --- Ultrasonic setup ---
    #define TRIG_PIN  9
    #define ECHO_PIN  8
    #define MAX_DIST  100  
    NewPing sonar(TRIG_PIN, ECHO_PIN, MAX_DIST);
    
    // --- RGB LED pins ---
    const int R_PIN = 3;
    const int G_PIN = 5;
    const int B_PIN = 6;
    
    void setup() {
      Serial.begin(9600);
      pinMode(R_PIN, OUTPUT);
      pinMode(G_PIN, OUTPUT);
      pinMode(B_PIN, OUTPUT);
    }
    
    void loop() {
      delay(100); // small delay between pings
    
      int distanceIN = sonar.ping_in();      // measure distance in inches
    
      if (distanceIN == 0) {  // out of range
        setColor(0, 0, 0);    // LED off
        return;
      }
    
      // --- Screen-distance ---
      if (distanceIN < 4) {        // Too close
        setColor(255, 0, 0);        // Red
      } else if (distanceIN <= 8) { // Ideal range
        setColor(0, 255, 0);        // Blue
      } else {                      // Too far
        setColor(0, 0, 255);        // Green
      }
    
      // Serial Monitor Reading
      Serial.print("Distance: ");
      Serial.print(distanceIN);
      Serial.println(" in");
    }
    
    // --- RGB helper function ---
    void setColor(int r, int g, int b) {
      analogWrite(R_PIN, r);
      analogWrite(G_PIN, g);
      analogWrite(B_PIN, b);
    }

Battery Life Estimate

Assuming an average LED draw of ~15 mA (one channel on at a time) plus the sensor and microcontroller overhead of ~35 mA, total is ~50 mA. With a 1200 mAh pack, runtime ≈ 1200 / 50 ≈ 24 hours (theoretical; regulator losses not included).

Measured vs. Theoretical Forward Voltage

Typical LED forward voltages: Red ≈ 2.0 V, Green ≈ 3.0 V, Blue ≈ 3.2 V. Using individual 220 Ω resistors per channel at 5 V limits current to a safe level and keeps brightness reasonably balanced.
